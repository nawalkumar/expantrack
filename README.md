Personal Expense Tracking System

Tech Stack: PHP, MySQL, JavaScript, HTML Canvas, Tailwind CSS, Bootstrap

Project Overview

A full-stack application for tracking personal expenses, allowing users to monitor daily, weekly, monthly, and yearly spending. The platform includes category-wise expense tracking, interactive graph visualizations, daily reminders, and secure user authentication, providing users with a complete financial overview.

Key Features

User Authentication: Secure login/signup implemented with PHP sessions.

Expense Tracking: Add and manage expenses across multiple categories (food, travel, bills, etc.).

Data Visualization: Dynamic graphs rendered using HTML Canvas display spending trends.

Responsive & Modern UI: Designed using Tailwind CSS and Bootstrap for a clean, accessible interface; optimized MySQL queries ensure secure and fast data handling.

Installation
Backend

Clone the repository:

git clone <your-repo-link>


Navigate to the project directory:

cd expense-tracking-system


Configure database in a .env or config.php file:

DB_HOST=<your-database-host>
DB_USER=<your-database-user>
DB_PASSWORD=<your-database-password>
DB_NAME=<your-database-name>


Run the application on your local server (XAMPP, WAMP, or LAMP).

Frontend

Open index.html or launch through your server.

Fully responsive design using Tailwind CSS and Bootstrap, works across devices.
